Rapports d'accident et rapports médicaux

L'application remplace les formulaires Jotform. Le directeur de course déclare l'accident, le médecin de l'épreuve complète un rapport par patient, et le service médical de la FFSA retrouve le dossier complet dans un back office sécurisé. Les captures viennent de l'application, avec des données fictives.

Accès

Des comptes autonomes pour les directeurs de course

Les licenciés FFSA se connectent avec leur compte licencié, sans validation. Les autres créent un compte, validé par la FFSA. À chaque connexion, un code est envoyé par e-mail.

Étape 1

Le directeur de course déclare l'accident

Le formulaire se remplit en étapes, sur ordinateur comme sur téléphone. La saisie est enregistrée au fur et à mesure : on peut fermer la page et reprendre plus tard. Le directeur de course suit ses déclarations sans jamais voir le rapport médical.

Étapes 2 et 3

Le médecin complète le rapport médical

Il reçoit un e-mail et un SMS sans aucune donnée de santé, seulement un lien. À l'ouverture, un code lui est envoyé pour confirmer son identité. S'il n'est pas le bon médecin, il transfère le dossier à un confrère.

Étape 4

Le service médical suit les dossiers

Deux rôles séparés : le service médical accède aux données de santé, l'administrateur gère les comptes sans jamais les voir. Connexion par mot de passe et application d'authentification. Chaque consultation, téléchargement et export est enregistré.

Version de démonstration

Tester l'application

La démo interactive s'ouvre dans le navigateur, sans compte ni installation, même hors connexion. Les comptes de test sont prêts, le code de connexion s'affiche à l'écran et les e-mails apparaissent dans la démo au lieu d'être envoyés. Chaque testeur a ses propres données fictives.

Ouvrir la démo interactive

  1. OuvrirCliquez sur Ouvrir la démo interactive. Le guide « Comment tester » s'affiche en bas à droite.
  2. DéclarerConnexion avec le compte « Directeur de course », puis « Déclarer un accident ».
  3. Jouer le médecinBandeau jaune « Voir les e-mails envoyés » : ouvrez le lien reçu par le médecin, puis son code dans la même boîte.
  4. ConsulterConnexion avec le compte « Service médical » et ouverture du dossier.
  5. NoterLe bouton Notes garde vos remarques écran par écran. Exportez-les en texte pour les transmettre.

Protection des données de santé

  • ChiffrementFormulaires, brouillons et pièces jointes chiffrés dans la base, clés renouvelables.
  • Deux rôles séparésLe service médical voit les données de santé. L'administrateur gère les comptes sans y avoir accès.
  • Accès cloisonnésLe directeur de course ne voit que ses déclarations, le médecin que son dossier.
  • Double authentification obligatoireCode par e-mail pour les directeurs de course, application d'authentification pour le back office.
  • E-mails et SMS sans données sensiblesUniquement une référence de dossier et un lien, jamais l'identité de la victime.
  • TraçabilitéJournal de tous les accès, impossible à modifier ou à effacer.
  • Conservation limitéeDossiers supprimés automatiquement après 10 ans. Page « Données personnelles » accessible à tous.
  • Pièces jointes contrôléesFormat vérifié et analyse antivirus avant tout enregistrement.
